# 前端卡资源本地化

为 SillyTavern 前端卡准备的在线资源备份扩展。它会扫描角色卡、消息和前端 iframe 中使用的 HTTP/HTTPS 图片、音频、视频链接，下载到酒馆本地并自动把原链接替换为本地资源路由。

资源默认保存在相对位置：

```text
SillyTavern/data/resources/角色卡名称/
```

因此换电脑、换盘符或分享酒馆目录时，资源会随 `data` 一起保留；不依赖某个固定绝对路径。

## 功能

- 自动扫描图片、音频、视频三类在线资源。
- 打开扫描窗口时逐个估算资源大小，可单独勾选或按类型批量选择。
- 下载后自动使用本地文件，原图床失效后仍可继续使用已备份的资源。
- 可随时切换在线模式、本地优先模式和严格离线模式；切换时原地替换媒体，不重置前端卡进度。
- 服务端插件断开时自动恢复原图床地址；前端每 5 秒静默检查一次，服务端重新连接后再恢复本地映射，无需手动刷新。
- 悬浮球以云朵/资源箱显示最新媒体来自云端还是本地；下载时外圈显示进度，悬停后才显示百分比。
- 可选资源嗅探通知：实时发现前端卡实际加载的图片、音频和视频，并按类型显示不同颜色。
- 可授权 `data/resources`，将浏览器可读取的嗅探资源直接保存进对应角色卡目录并登记本地映射。
- 右下角悬浮球显示下载进度；多张卡同时下载时用不同颜色区分队列，点击可轮换查看。
- 下载完成后，悬浮球默认只显示未下载或下载失败的资源，便于再次尝试。
- 可管理当前卡或所有卡的本地资源：查看、打开文件夹、删除选中资源、删除整张卡资源。
- 所有卡列表会静默刷新，外部新增或删除文件夹后会自动反映。
- 内置后端安装器与版本检测：后端缺失或版本过旧时，会提示授权 `SillyTavern/plugins` 文件夹进行安装或覆盖更新。
- 外站扫描和下载均采用单资源串行；默认请求启动间隔为 1 秒，并可为不同网站配置独立速率。内置的猫箱资源域名 `files.catbox.moe` 默认间隔为 5 秒。

## 安装

### 1. 安装前端扩展

在 SillyTavern 的“扩展程序”页面点击“安装扩展程序”，输入：

```text
https://github.com/bronie-honkai/frontend-media-localizer
```

安装完成后刷新页面或重启酒馆。

### 2. 用扩展安装后端

首次加载时，如果后端未安装或版本低于前端要求，会出现“安装/更新资源本地化后端”窗口：

1. 点击“选择 plugins 文件夹并安装”。
2. 在系统文件夹选择框中选择 `SillyTavern/plugins`，不要选择酒馆根目录。
3. 扩展会写入 `plugins/frontend-media-localizer/index.mjs` 和 `package.json`。
4. 完全重启 SillyTavern。

后端安装成功后，设置页的运行状态会显示连接状态和当前后端版本。

### 3. 启用酒馆服务端插件

打开 `SillyTavern/config.yaml`，确认存在：

```yaml
enableServerPlugins: true
```

保存后重启酒馆。若这里是 `false` 或不存在，酒馆不会加载后端，下载、打开文件夹和本地路由功能不会生效。

## 使用方法

1. 打开一张含在线资源的角色卡或前端卡。
2. 右下角出现资源悬浮球时点击它，选择“扫描下载”。也可从扩展设置里的“扫描下载”进入。
3. 在扫描窗口按图片、音频、视频批量选择资源，等待大小估算结束。
4. 点击“下载所选资源”。窗口会关闭，悬浮球改为圆形进度条。
5. 下载完成后，资源会自动映射到本地；悬浮球再次点击可重新检查遗漏和失败项。

## 资源管理

扩展设置页提供三层管理：

- 当前角色卡：扫描、管理资源、打开当前卡文件夹。
- 所有角色卡资源：实时列出已有本地资源的卡片。
- 每张卡右侧图标：文件夹为打开目录、垃圾桶为删除整张卡资源、眼睛为查看该卡资源清单。

删除操作会删除 `data/resources/对应卡名` 下的文件。重要资源建议先通过“打开文件夹”自行备份。

## 网站请求速率

扩展设置中的“网站请求速率”支持：

- 修改所有未单独配置网站使用的默认最小请求间隔。
- 添加任意域名规则，例如 `files.catbox.moe` 或 `example.com`。
- 域名规则同时匹配该域名及其子域名；更具体的长域名优先。
- 估算资源大小和正式下载共用相同规则，保存后对后续请求即时生效。
- 可配置范围为 0.1–3600 秒；请求仍保持单资源串行。

## 资源嗅探与手动四步补偿

资源嗅探默认关闭。开启后可进一步配置通知、自动下载、失败补偿、通知数量与显示时间：

- 通知默认最多 3 条并在 5 秒后消失；自动下载失败的通知会保留，等待用户处理。
- 自动下载只执行第 1 步服务端直连；失败后停在第 2 步，后续每一步都必须由用户再次点击按钮。
- 第 2 步由浏览器读取一次资源 Blob 并上传给酒馆服务端；失败后保留 Blob 并停在第 3 步。所有可能访问图床的请求仍遵守网站速率。
- 第 3 步只复用第 2 步已经取得的 Blob；用户点击时才检查或申请备用目录授权，失败后停在第 4 步。
- 第 4 步优先把同一 Blob 下载到浏览器默认下载目录；下载完成后再次点击“导入”并选择文件。仅当第 2 步因 CORS 拿不到 Blob 时，才退回原图床链接普通下载。
- 后端离线时允许先写入文件并记录待登记项，后端恢复后自动验证和同步索引。

## 下载失败怎么办

扩展不会伪造下载结果。图床服务器不可访问、超时、403 防盗链、资源已经失效时，该条会标记为失败；重新点击悬浮球即可看到失败项并再次尝试。

如果某个图床整体不可访问（例如 catbox 暂时故障），需要等图床恢复后重试。已经成功保存到本地的文件不受影响。

## 文件结构

```text
frontend-media-localizer/
├─ index.js                 前端扫描、悬浮球、队列与管理界面
├─ style.css                扩展样式
├─ manifest.json            SillyTavern 前端扩展清单
└─ server-plugin/           随扩展发布的后端安装模板
   ├─ index.mjs             下载、文件路由、资源索引接口
   └─ package.json
```

安装后端后，酒馆目录中还会有：

```text
SillyTavern/
├─ plugins/frontend-media-localizer/  酒馆启动时加载的服务端插件
└─ data/resources/                    按角色卡保存的本地媒体
```

## 注意事项

- 文件夹授权只用于安装后端模板；日常下载由酒馆服务端写入 `data/resources`，不需要重复授权。
- 仅处理 HTTP/HTTPS 的图片、音频、视频资源，不下载网页、脚本或其他未知文件。
- 请只安装自己信任的扩展及后端代码。

## 更新

前端扩展可用酒馆的“更新扩展程序”功能更新。新版前端会自动读取服务端版本；检测到旧版时暂停新的扫描与下载，并弹出更新窗口。点击更新、授权同一个 `SillyTavern/plugins` 文件夹并确认覆盖，随后完全重启酒馆即可。
